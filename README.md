-> Task Manager

A responsive task management web application built with HTML, Tailwind CSS, and JavaScript.

-> Features

- Create, read, update and delete tasks
- Mark tasks as completed
- Restore the previous task status
- Filter tasks by status
- Organize tasks by priority
- Dashboard with task summary counts
- Task details modal
- Success, update & delete notifications
- Light/Dark mode
- Responsive design
- Tasks are saved in localStorage

-> Tech Stack

- HTML5
- Tailwind CSS
- JavaScript
- localStorage
- Font Awesome
- Google fonts

-> Pages

* Dashboard — Task overview and summary counts
* My Tasks — View and filter tasks by status
* Priorities — View tasks grouped by high, medium, and low priority

-> Getting Started

1. Clone the repository.
2. Install the project dependencies.
3. Run the Tailwind CSS development command.
4. Open the project in your browser using Live Server or your preferred local development server.
